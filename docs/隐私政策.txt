投屏Window 桌面版 · 隐私政策
版本：2.0.0
最后更新：2026-10-11

一句话结论：**本软件不联网收集、不上传任何关于你的数据。** 投屏画面、截图、录像、设置
全部只存在于你自己的电脑上。

────────────────────────────────────────
一、本软件会接触哪些数据，存在哪里
────────────────────────────────────────
| 数据 | 存放位置 | 是否加密 | 说明 |
| --- | --- | --- | --- |
| 投屏画面 | 仅内存 | — | 实时解码显示，不落盘（你自己点截屏/录制才会保存） |
| 截图与录像 | `%LocalAppData%\CastReceiver\vault\` | **加密** | 只能用你的账号密码在本程序内查看 |
| 账号名与密码校验信息 | 同上（加密库内） | **加密** | 密码本身不以明文保存；密钥不写入磁盘 |
| 设置 | `%LocalAppData%\CastReceiver\settings.json` | 否 | 设备名、外观、端口、各项开关等 |
| 设备标识 | 同上 | 否 | 首次运行随机生成的 UUID，仅用于本机识别设备，不含任何硬件指纹 |
| 运行日志 | `%LocalAppData%\CastReceiver\castreceiver.log` | 否 | 排障用，超过 4 MB 自动滚动；详见第三节 |
| 启动跟踪 | 同上 `startup.log` | 否 | 每次启动覆盖写入，仅记录启动各阶段耗时 |

加密库的位置可以在「设置 → 画面」里看到，也可以在程序内清空或删除。
**如果你把加密库文件夹整个拷到别的电脑，没有密码同样打不开** —— 这是设计目标，不是缺陷。

────────────────────────────────────────
二、本软件不会做的事
────────────────────────────────────────
· 不注册账号、不需要登录任何服务器；
· 不上传投屏画面、截图、录像、密码或设置；
· 不收集设备指纹、使用统计、崩溃报告，**没有遥测**；
· 不在后台自动检查更新（更新检查必须由你在「设置 → 关于」手动点击触发）；
· 不内置广告、不做行为分析；
· 不会因为"你用了免费版"而限制画质或插入水印。

────────────────────────────────────────
三、关于日志（唯一需要你留意的本地痕迹）
────────────────────────────────────────
本软件区分两类日志：

1. **普通运行日志**（排障用）：网络状态、编解码错误、功能开关等。会写入上面那张表里的
   `castreceiver.log`。你可以在「设置 → 安全」里点「清除日志文件」随时删除。
2. **投屏会话事件**（谁、什么时候连上/断开）：默认**不写磁盘**，只在界面里显示。
   这是刻意的设计——投屏的开始与结束时间不应该留在磁盘上被别人看到。
   该行为由「设置 → 安全 → 隐私日志」控制；只有你主动打开这一项，会话事件才会落盘。

另外：录制或截屏时，如果本机开启了「防截屏」，程序内部的取帧会走一条临时降级路径
（详见下节），这不涉及任何对外传输。

────────────────────────────────────────
四、对外网络行为（全部在本机局域网内）
────────────────────────────────────────
本软件接收投屏时需要在本机监听端口并做局域网广播（mDNS / SSDP / RTSP / HTTP），
目的是**让你的手机能在同一个 Wi-Fi 里发现这台电脑**。这些都是局域网内的通信，
不会把你的画面发到互联网上。

唯一的**主动对外请求**是：当你在「设置 → 关于」填入更新源地址并点击「检查更新」时，
程序会向该地址发一次 HTTP GET，用于读取最新版本号。
内置的官方更新源当前**尚未配置**（留空即不做任何检查）；新版本发布信息通过作者的 QQ（2718860462）告知。

开启「一键准备」时，程序会请求一次管理员授权，用于添加防火墙放行规则和允许本机被发现。
这一步只改本机防火墙，不涉及数据传输。

────────────────────────────────────────
五、本机隐私加固功能（可选，默认按你的设置生效）
────────────────────────────────────────
· **防截屏**：开启后，其他程序截取本窗口只能得到黑屏（调用 Windows 的
  `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`）。
  代价说明：本机 `PrintWindow` 取帧会因此拿不到画面，程序会退化为"截图时瞬时解除保护"，
  或在录制期间按你的设置暂停保护——**这一点在「设置 → 安全」里有明确提示，不会偷偷进行**。
· **画面遮挡**：一键把画面收起并盖上遮挡面板，投屏不中断；也可设定锁屏/切换用户时自动遮挡。
· **空闲自动上锁**：加密库在设定时长无操作后自动上锁，内存中的密钥被清除。
· **隐私体检**：检查并（可选）关闭 Windows Game Bar 的后台录制等系统性录屏入口。

────────────────────────────────────────
六、随附的第三方程序
────────────────────────────────────────
**当前版本的安装包内不包含 adb 或其他可执行第三方工具。**
「安卓鼠标控制」功能已按需求停用，Android 官方调试工具 adb 的二进制仅保留在源码仓库中
（不在发布包里）。若将来恢复该功能，adb 只会在你主动打开开关时连接你指定的手机，
不会连接任何第三方服务器。其余组件见随附的《第三方声明》。

────────────────────────────────────────
七、儿童与未成年人
────────────────────────────────────────
本软件不是面向儿童设计的产品。若未成年人使用，请在监护人指导下进行，
尤其注意不要录制、传播涉及他人隐私的内容。

────────────────────────────────────────
八、你的权利
────────────────────────────────────────
· 随时可以删除 `%LocalAppData%\CastReceiver\` 整个文件夹，这会清空设置、日志与加密库
  （**加密库一旦删除无法恢复**）；
· 随时可以卸载本软件，卸载不会自动删除 `%LocalAppData%\CastReceiver\`，
  需要你自行删除（避免误删你的加密内容）；
· 本地数据不需要"导出"或"撤回同意"流程，因为它从未离开你的电脑。

────────────────────────────────────────
九、政策变更
────────────────────────────────────────
本政策如随版本变化，会在软件内的「关于」页面给出新版本号与更新日期。
若未来引入任何形式的联网收集功能，会在此明确列出并默认关闭。
