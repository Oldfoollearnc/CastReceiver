# 投屏Window · UI 设计方案（2.3 一版）

> 现状：界面已经收敛到"中性近黑 + 薄荷绿、无渐变、1px 描边"。这一版不再改动视觉方向，
> 只补三件事：**等待感的消除、控制的可发现性、以及一套能长期维护的令牌与规则**。
> 原则优先级：性能 > 按钮与交互 > 装饰。

---

## 1. 三条设计原则

1. **界面先可用，再谈动效。** 任何"转圈/进度"都不能挡住已经能用的界面；
   准备过程用文字状态表达（顶栏一句话 + 舞台副标题），不用全屏遮罩。
2. **默认最优，手动可选。** 画面适配默认"自动（不裁切）"；只有在用户明确要改时才展开按钮。
   默认状态下界面元素越少越好，手动入口要"藏得住但找得到"。
3. **控制浮在内容上，就别赖着不走。** 悬浮条、音量弹层都是"用完即走"：
   3 秒无操作收起、点外侧立即消失、鼠标回到画面立刻出现。

---

## 2. 设计令牌（建议逐步替换硬编码）

| 类别 | 令牌 | 取值 | 用途 |
| --- | --- | --- | --- |
| 间距 | `Sp.1 / 2 / 3 / 4 / 5` | 4 / 8 / 12 / 16 / 24 | 控件内边距、区块间距 |
| 圆角 | `R.Control / Card / Bar` | 8 / 14 / 14 | 按钮 / 卡片 / 悬浮条 |
| 字号 | `Fs.Caption / Desc / Body / H2 / H1` | 10.5 / 11.5 / 13 / 15 / 22 | 与现有设置页一致 |
| 描边 | `1px` + `B.Line` / `B.LineSoft` | — | 分层只靠描边与明度，不用阴影堆叠 |
| 动效 | `Mo.Fast / Base / Slow` | 180 / 280 / 520 ms | 悬停 / 淡入 / 入场 |
| 强调 | `B.Accent`（默认 `#3DDC97`） | 可换 5 套 + 跟随系统 | 只用于"当前状态"和主操作 |

**规则**：同一屏最多一个强调色元素；不用渐变、光晕、彩色阴影；深色下不使用纯黑背景（`#0A0B0D` 起）。

---

## 3. 本轮已落地（可直接对照代码）

- **启动**：不再有"黑屏 → 转圈 → 主界面还转圈"。原生闪屏改为品牌启动画面（名字 + 呼吸细线 + 步骤），
  主窗口首帧即可用，接收端在后台就绪（顶栏"正在准备"、舞台副标题"正在准备接收端…"）。
- **悬浮条**：默认 3 秒无操作收起（设置可选 0/2/3/5/8 秒）；鼠标移回画面或停在条上立即出现。
- **小窗**：未投屏时按钮禁用（与截屏/录制一致），右键菜单同步。
- **音量弹层**：点外侧立即消失、Esc 关闭、5 秒空闲自动收起。
- **全屏适配**：自动模式默认开启（不裁切、等比最大化），手动按钮整组收起；
  全屏时通过悬浮条的「画面适配」菜单仍可改 自动/适应/铺满/拉伸/原始 与缩放。

---

## 4. 主界面分区（维持四段式）

```
┌ 顶栏 ────────────────────────────────────────────────┐
│ 品牌 · 本机名        一句状态（等待/连接/投屏）      一键准备 · 外观 · 设置 · 窗控 │
├ 舞台 ────────────────────────────────┬ 侧栏 ─────────┤
│ 舞台顶栏：状态点 / 设备名 / 副标题     │ 本次投屏 / 上手引导 │
│                              [自动] [全屏]            │                 │
│                                                       │                 │
│                     画面 / 待机 3D                     │                 │
│                                                       │                 │
│                    （悬浮条：截屏/录制/小窗/音量）      │                 │
├ 底栏 ────────────────────────────────────────────────┤
│ ● 状态文字                          F11 全屏 · 快捷键 · 版本号            │
└───────────────────────────────────────────────────────┘
```

**信息层级**：顶栏回答"现在是什么状态"，舞台回答"看到了什么"，侧栏回答"本次投屏的细节"，
底栏回答"还能按什么"。任何一句话只出现在其中一层，不重复。

**下一步（P1）**：侧栏"本次投屏"合并为两行摘要（时长 + 已保存数量），详情点开抽屉；
未连接时整块侧栏收起成一条窄把手（已有折叠能力，可把默认值改为"未连接时自动收起"）。

## 5. 交互细则

### 5.1 悬浮条
- 出现：鼠标移入画面、从最小化恢复、切换全屏、点任何条上按钮后。
- 收起：无操作达到设置秒数；或窗口最小化 / 进入开屏动画。
- 不收起：鼠标停在条或音量弹层上；音量弹层打开期间。
- 全屏时多两枚：退出全屏、画面适配（窗口模式不重复舞台顶栏的按钮）。

### 5.2 弹层（音量 / 适配菜单）
- 单层：一次只开一个弹层，开新的先关旧的。
- 关闭：点外侧、Esc、空闲超时三者任一。
- 位置：贴着触发按钮，超出工作区时自动夹回屏幕内。

### 5.3 等待与空态
- 启动：不遮罩，状态写进顶栏；唯一允许的遮罩是"一键准备网络 / 重启接收端"这类用户主动触发的长操作。
- 连接中：舞台中央显示轻量进度（已有），超过 20 秒给出"重启接收端"的可操作建议。
- 未连接：3D 转台 + 三步就位提示；不出现任何"转圈"。

### 5.4 全屏
- 双击画面 / F11 进入，Esc / 双击退出；退出后恢复原窗口位置与大小。
- 全屏默认自动适配（不裁切）；用户手动选过则尊重选择，不再自动改。

## 6. 设置页信息架构

保持"左侧导航 + 分组行"，但把同类项按"使用频率"排序：

1. **通用**：设备名、开机启动、最小化到托盘、动效、主题与强调色、快捷键。
2. **画面**：自动适配（推荐）→ 手动适配 → 缩放 → 画质档位 → 全屏行为 → 悬浮条自动消失 → 小窗。
3. **网络**：接收端开关、AirPlay、防火墙、诊断入口。
4. **安全**：隐私模式、设备名显示、抢占、键盘回传、反截屏、会话锁屏。
5. **诊断 / 关于**：自检、日志、版本、法务文本。

**规则**：每个开关下面必须有一句"关掉会怎样"；危险操作（清空库、删除旧文件）用独立区块 + 确认。

---

## 7. 可访问性与键盘

- 所有图标按钮都有 `AutomationProperties.Name`（已基本覆盖），悬浮条按钮补齐禁用态说明。
- 键盘：Tab 顺序按"顶栏 → 舞台顶栏 → 侧栏 → 底栏"；F11 / Esc / 双击 三条全屏路径并存。
- 对比度：正文不低于 4.5:1；`B.TextFaint` 只用于次要说明，不承载关键状态。
- 动效开关（设置 → 通用）关闭后，所有位移/缩放动画退化为直接到位（`Motion.Enabled=false`）。

## 8. 后续排期

| 优先级 | 事项 | 验收标准 |
| --- | --- | --- |
| P0 | 侧栏"未连接时自动收起" | 未投屏时画面区更宽；投屏后自动展开一次 |
| P0 | 悬浮条按钮顺序/分组按使用频率重排 | 截屏与录制相邻，音量与静音合并为一个弹层 |
| P1 | 舞台顶栏的"自动"小标加一句 hover 说明 | 用户一眼知道"不裁切"的含义 |
| P1 | 设置页搜索/最近使用 | 输入"音量"能定位到相关分组 |
| P2 | 浅色主题下的卡片层级复核 | 亮色下不靠阴影也能分出层次 |
| P2 | 高对比度模式（系统）适配 | 系统开启高对比度时描边与文字自动加强 |

---

## 9. 明确不做

- 不做"科技感"渐变、光晕、粒子背景（2.2 已回退过一次）。
- 不为了动效牺牲首帧时间：入场动效只动 Opacity / Transform，不触发布局。
- 不在画面上叠加常驻控件；所有控制都必须能收起。
